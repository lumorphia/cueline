### 公開ゲート (RM-31)

公開 (URL を人に教える) の前に、全部を済ませる。

- 正式名を決め、リポジトリ・パッケージのスコープ・画面の名前を置き換える
- `<正式名>.lumorphia.com` を当て、lumorphia/website に載せる
- 画面と README に「ゲームに触れないタイマーであること」「FINAL FANTASY XIV の運営とは関係が無いこと」を書く (ADR-0005)
- 要件 11.3 の完了条件を、PoC と同じ端末で手で確かめる (30 分の連続再生を含む)
- `SECURITY.md` の報告先が動くこと

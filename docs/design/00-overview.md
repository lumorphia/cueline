# 00. 概要

## 何をするか

利用者が書いたタイムライン (スクリプト) を読み込み、戦闘の開始に合わせて時計を進め、決めた時刻に声と画面で知らせる (コールする)。ブラウザだけで動き、サーバーを持たない (ADR-0002)。

使い方は 2 つ (要件 1.5)。

- **PC の別モニタ**: ゲームと同じ PC のブラウザで開き、マウスで操作する。PC から鳴らす
- **スマホ・タブレット単体**: 手元に置き、タッチで操作する。その端末から鳴らす (ADR-0009)

## 何をしないか

- ゲームのプロセス、メモリ、通信、ログ、画面、入力に触れない (ADR-0005)
- サーバーに利用者のデータを送らない。ログインも持たない (共有を作るまで。ADR-0012)
- 端末をまたいだ操作 (スマホをリモコンにして PC を鳴らす)
- スクリプトの中のコードを実行しない (ADR-0007)

## 用語

| 用語             | 意味                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| スクリプト       | 利用者が書く YAML / JSON のファイル。タイムラインの定義 (02)                                       |
| タイムライン     | スクリプトを検証・展開した後の、エンジンが使う内部の形                                             |
| フェーズ         | タイムラインの区切り。時刻で始まる (`absolute`) か、利用者の操作で始まる (`manual`)                |
| イベント         | ギミックなど、ある時刻に起きること。フェーズの開始からの秒数 (`at`) を持つ                         |
| 通知             | イベントに付く知らせ。読み上げ (`speech`) か画面表示 (`display`)。イベントより `before` 秒先に鳴る |
| コール           | 通知が実際に鳴ること                                                                               |
| 論理時刻         | タイムラインの上での今の時刻 (秒)。0 が戦闘開始 (プル)。プルカウント中は負になる (03)              |
| フェーズ時刻     | 今のフェーズの開始からの秒数                                                                       |
| プルカウント同期 | ゲーム内のカウントダウンと同時に押し、0 で自動で戦闘を始めること (ADR-0008)                        |
| イベント同期     | 「いまこのイベントが起きた」と押して、論理時刻をそのイベントに合わせること (ADR-0008)              |
| 実行済み         | 通知が鳴った (`fired`) か、時刻を飛び越えて鳴らさなかった (`skipped`) 状態 (ADR-0006)              |
| タグ             | 通知に付ける任意の印。利用者が聞くタグを選ぶ。ロールの区別に使う (要件 FR-006)                     |
| 音声パック       | PC で VOICEVOX を使って作った音声を、タイムラインと一緒にまとめたファイル (P1、ADR-0010)           |

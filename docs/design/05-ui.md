# 05. 画面

`apps/web`。React。画面の文言は辞書から引く (ADR-0011)。

## 画面の一覧

| 画面       | 中身                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------- |
| ライブラリ | 保存したスクリプトの一覧。読み込み (ファイル、貼り付け、サンプル)、新しく作る、直す、書き出し (YAML / JSON)、消す       |
| 読み込み   | 貼り付けの入力欄と、検証の結果 (エラーと警告を、場所と直し方つきで並べる)                                               |
| 再生       | 下。アプリの中心                                                                                                        |
| 設定       | 声 (エンジン、声、速さ、音量、高さ、テスト)、競合の方式、聞くタグ、プルカウントの既定、補正の単位、次の件数、言語、表示 |

画面の数が少ないので、ルーターは入れず、`App` の状態でライブラリと再生を切り替える (RM-24)。最後に開いたスクリプトを覚えておき (`tc:last`)、開き直したときはそこから始める (戦闘の合間に開き直してすぐ使えるように)。URL で画面を指せる必要が出たら見直す。

## エディタ (RM-33、要件 FR-004)

YAML / JSON を書けない利用者も、画面だけで作れるようにする。ライブラリの「新しく作る」と、各スクリプトの「直す」から開く。

```
サンプル: 水晶のゴーレム            [記録して作る] [保存] [閉じる]
名前 [            ]  言語 [ja-JP ▾]  プルカウント [15] 秒  既定の何秒前 [3]
タグ  (タンク ×) (ヒーラー ×) [+ タグ]

フェーズ1   開始 (●時刻で 0:00  ○手動)                     [↑][↓][消す]
 時刻    イベント        コール              何秒前  タグ      種類
 [0:08 ] [クリスタルロア] [5秒後、全体攻撃  ] [5 ]  [     ▾] [声 ▾]  [+通知][複製][消す]
         └ 通知 2       [全体攻撃          ] [5 ]  [     ▾] [画面▾]  [消す]
 [0:20 ] [シャードバスター][タンク強攻撃    ] [3 ]  [tank ▾] [声 ▾]
 [+ イベントを足す]
[+ フェーズを足す]
```

- 編集の中身は `Script` (読み込んだ後の形) をそのまま、変えずに新しく作って持つ。検証は `serializeScript` → `parseScript` で、読み込みと同じ規則にする。問題のパス (`phases[0].events[1].notifications[0].text`) で欄を探し、その欄に文言を出す
- ID は自動で付ける。フェーズは `p1`・`p2`…、イベントは `e1`・`e2`…、タグは `t1`・`t2`…、スクリプトは `my-` と乱数。使っている番号とぶつからないようにする
- 時刻は「分:秒」でも秒でも受け付け、欄を離れたときに確定する。行は時刻の順に並べ直す (打っている途中では動かさない)
- 1 つのイベントに通知が 2 つ以上あるとき (声と画面など) は、行の下に字下げして並べる
- 保存すると、元のスクリプトと同じ形式 (YAML / JSON) で書き直す。YAML のコメントは消えるので、コメントのあるスクリプトを初めて直すときに知らせる
- 保存していない変更があるまま閉じるときは、確かめる
- スマホでは行をカードにする (時刻とイベント名を 1 段目、コールと何秒前を 2 段目)

### 記録して作る (RM-34、要件 FR-008)

```
記録中  00:23.4  フェーズ1
              [  い ま  ]          ← 大きなボタン。Space でも押せる
[次のフェーズ]  [取り消し]  [終える]
足したイベント: 0:08 イベント1 / 0:20 イベント2
```

- プルカウントか開始で時計を動かし、「いま」を押すたびに、その時刻 (0.1 秒に丸める) のイベントを今のフェーズに足す。名前は「イベント N」、コールは名前と同じにしておき、後で表で直す
- 「次のフェーズ」で、そこから手動のフェーズとして記録する (フェーズ時刻は 0 から)
- 「取り消し」は直前に足したものを消す。「終える」で表に戻る
- 時計はエンジンと同じく、単調時計から毎回計算する

## 再生画面

戦闘中は一瞬しか見ない。**今のフェーズ、次のイベント、残り秒数** が一目で分かることを最優先にする (要件 FR-301〜FR-303)。

```
┌───────────────────────────────────────────┐
│ フェーズ1                     戦闘中  02:31.4 │  状態と論理時刻 (フェーズ時刻は小さく)
├───────────────────────────────────────────┤
│  5.2  クリスタルロア    「5秒後、全体攻撃」    │  次のイベント (大きく、残り秒数のバー)
│ 17.9  シャードバスター  「タンク強攻撃」 [T]   │
│ 31.0  プリズム散開      「散開」               │  次の N 件 (既定 5)
│ ───────────────────────────────────────── │
│  済  ロックフォール     「頭割り」             │  実行済みは薄く、上に流す
├───────────────────────────────────────────┤
│ [いま: クリスタルロア] [いま: シャードバスター] │  イベント同期 (次の 3 件)
│ [ -1s ] [ +1s ] [フェーズ ▾] [取り消し]         │  補正
│ [ プル 15s ] [ 開始 ]  [ 一時停止 ]  [■ 長押し] │  再生の操作
└───────────────────────────────────────────┘
```

- `display` の通知は、画面の上半分に大きく 3 秒出す
- 状態の色: カウント中・戦闘中・一時停止・ずれの警告 (`onMissed`) を色と文字の両方で示す
- 停止は長押し (1 秒) か 2 回押し。誤って押すと何も鳴らなくなるため (03)
- 補正の後は「取り消し」が 5 秒光る
- `manual` のフェーズが次にあるときは、「フェーズ2 を開始」のボタンを大きく出す
- 押せるものは 48px 角以上
- 読み上げの声のクレジット (VOICEVOX のとき) を下に小さく出す

## レイアウト

| 使い方             | 向き           | 配置                                                               |
| ------------------ | -------------- | ------------------------------------------------------------------ |
| PC の別モニタ      | 横長、狭い窓も | 時刻と次のイベントを左、操作を右。窓の幅が狭いとスマホの配置になる |
| スマホ・タブレット | 縦             | 上に時刻と次のイベント、下に操作 (親指の届く範囲)                  |

- スマホは画面の自動ロックを止める (Wake Lock、ADR-0009)。取れないとき・外れたときは上に帯で出す
- スマホの縦向きでは、画面の高さに収め (`h-dvh`)、余りを次の通知に回す。フェーズの開始はイベント同期の列の先頭に置く (横にスクロールしても見えるように)。補正と停止は 4 列、再生の操作は 3 列の格子
- コンパクト表示 (要件 FR-304、P1): 時刻と次の 2 件だけ。将来のオーバーレイの下書きを兼ねる
- 暗い表示 (P1): 画面を点けっぱなしにするので、黒地に暗めの文字のモードを用意する

## 操作の割り当て

戦闘中はゲームに入力が向くので、キーボードのショートカットは補助にとどめる (別モニタのブラウザに入力を戻したときにだけ効く)。

| キー  | 操作            |
| ----- | --------------- |
| Space | 一時停止 / 再開 |
| ← / → | -1s / +1s       |
| Z     | 取り消し        |

## テスト

- 表示の規則 (残り秒数の書式、実行済みの並び) は単体テスト
- 画面をまたぐ流れ (サンプルを読み込む → プルカウント → 鳴る → 補正 → 取り消し) は Playwright の E2E。Web Speech は偽物に差し替え、呼ばれた文と時刻を見る
- スマホのレイアウトは Playwright の端末のエミュレーションで見る。実機の挙動 (Wake Lock、音のアンロック) は PoC と手での確認

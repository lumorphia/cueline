# PoC-001 タイマーの精度 (計測ページ)

[docs/design/08-poc.md](../../docs/design/08-poc.md) の PoC-001 を測るための、依存の無い静的ページ。エンジンと同じ作り (論理時刻は毎回時計から計算、タイマーは次の予定まで 1 本、早く起きたら張り直す) で、予定の時刻と気づいた時刻の差 (遅れ) を記録する。本体からは import しない。

## 動かす

PC (localhost は secure context なので Wake Lock 以外は全部使える):

```sh
python3 -m http.server 8731 --bind 127.0.0.1 -d spikes/poc-001-timer
# http://127.0.0.1:8731/ を開く
```

スマホは HTTPS が要る (Wake Lock、secure context)。プレビューの配信 (RM-12) に載せて開く。

## 測る組み合わせ

1 回 35 分。条件を変えて回し、毎回 CSV を保存する。

| #   | 端末               | 表示                                 | タイマー | AudioContext       | Wake Lock |
| --- | ------------------ | ------------------------------------ | -------- | ------------------ | --------- |
| 1   | PC (FF14 を動かす) | 別モニタで見えている、フォーカスなし | Worker   | なし               | -         |
| 2   | PC                 | 同上                                 | メイン   | なし               | -         |
| 3   | PC                 | 別のタブを前 (隠れる)                | Worker   | なし               | -         |
| 4   | PC                 | 同上                                 | メイン   | なし               | -         |
| 5   | PC                 | 同上                                 | メイン   | 無音               | -         |
| 6   | PC                 | 同上                                 | メイン   | 聞こえない小さな音 | -         |
| 7   | PC                 | 最小化                               | Worker   | 無音               | -         |
| 8   | iPhone Safari      | 画面点灯                             | Worker   | 無音               | あり      |
| 9   | Android Chrome     | 画面点灯                             | Worker   | 無音               | あり      |

途中で表示を切り替えてもよい (記録は 1 件ごとに `visibility` と `focus` を持つ。画面の結果も状態ごとに分けて出す)。

## 見るところ

- **積もり**: 最初の 1/10 と最後の 1/10 の遅れの中央値の差。設計上 0 付近になるはず。積もっていれば作りの誤り
- **見えている状態の p95 / 最大**: 目安は p95 ≤ 50ms、最大 ≤ 250ms
- **隠れたときの遅れ**: 1 秒前後に丸められるか、1 分単位まで間引かれるか。Worker と AudioContext で緩むか
- **早起き**: タイマーが予定より早く起きた回数。多くても害は無い (張り直すだけ) が、Worker とメインの違いとして記録する

## 結果の置き場

`docs/spikes/poc-001-timer.md` に、端末・ブラウザの版・条件ごとの p50 / p95 / 最大・積もり・気づいたことを書く。CSV はリポジトリに入れない (大きいので、要点の数値だけ写す)。
